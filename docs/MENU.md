# CLI 3.3 中文工作台

双击 `scantailor-cli.exe`，或运行 `scantailor-cli.exe menu`。便携包自带 Python；源码构建可指定 `menu --python <python.exe>`。自动化命令继续输出 JSONL，无参数且输入输出重定向时不会打开菜单。

## 创建任务

首页按输入文件、保存位置、处理方案分为三个区域。支持粘贴路径、浏览文件和选择文件夹；输入未就绪时预览/处理按钮置灰。导入后自动建议独立输出文件夹，已有目录保留以便识别和确认重复任务；同名路径是文件时才建议编号目录。可编辑尚未创建的输出目录，任务开始时创建。

粘贴地址支持 Ctrl+V、Shift+Insert 和右键；终端自身粘贴产生的文本也会被正常接收。支持中文、空格、资源管理器“复制为路径”的引号、每行一个路径和多条带引号的路径。输入框支持 Ctrl+A、左右移动、Home/End、Shift 选区、鼠标定位、Backspace/Delete 和替换选区。带初始值的字段自动全选，粘贴不会把新地址拼接在旧地址后面。

多行地址框的 Enter 表示换行，Ctrl+Enter 或“识别路径”按钮确认。粘贴中的换行不会意外提交或启动任务。路径错误在输入区域保留文本供修改；识别后显示文件数量及顺序，确认后才导入。目录可选择本层或包含子目录；PDF、图片和项目不能混为同一个任务。

## 设置与预览

“保真整理”“黑白文档”与“自定义”提供常用入口。常用设置包含纠偏、单双页、输出颜色/DPI、边距和疑难页策略；修改保留在草稿中，应用后才生效。切换自动/关闭纠偏会清除冲突的手动角度，手动边距会关闭自动边距，保真方案明确使用保留原页的疑难页策略。

“全部设置”保留 schema 2 的六阶段设置、项目规则、坐标/区域/展平曲线、运行选项、指定阶段分析与预览。高级字段使用中文名称，算法专名保留。逻辑页与源图规则、结构编辑、导出和 GUI 图形编辑仍可使用；原有配置文件和自动化命令兼容。

首页“预览几页”在渲染和处理前选择首、中、尾源页，少于三页时去重；运行选项可改为指定源页列表（如 1,5,9）。9 页 PDF 默认只渲染和处理 3 个源页。拆页后结果数可能增加；快速模式不计算整书统一布局，也不接受按页规则。需要按页规则或全项目统一布局时，选择“指定阶段预览”并确认完整分析范围。预览不会生成最终完整 PDF。

预览完成后可打开本地 `preview.html`，提供左右对比、只看原图、只看结果、放大及翻页；不上传图片。预览文件只读取该任务当前报告，PDF 使用 batch-report 的当前结果列表，避免混入旧处理版本。

## 处理与恢复

处理界面显示当前阶段、完成页数、进度、文件和耗时；详细日志单独展开。原生 JSONL 新增 `phase_started`（stage/total），`page_finished` 增加 completed/total。PDF 包装层持续转发原生进度。退出码 1 仍明确表示复核/部分失败，不能当成全部成功。

运行时设置锁定，取消发送 Ctrl+Break 并等待可用检查点写完。任务记录恢复使用原始输入和配置快照；不会混入当前表单改动。输入改变会清除旧作用范围和预览状态。项目结构编辑先应用当前参数，GUI 项目通过原生保存接口重定位路径后打开。

## 显示与开发关系

宽窗口显示双栏，普通窗口显示单栏；过小窗口提示放大并保留输入。文字按显示单元处理中文宽度，按钮命中区域与绘制来自同一布局，画面只更新改变的行以减少闪烁。Windows/终端自己的快捷键由系统控制。

`console.py` 管理原生剪贴板、输入事件和焦点；`editing.py` 处理文本选区与路径解析；`rendering.py` 管理单元格布局、颜色和命中区域；`workbench.py` 编排首页和常用设置；`ui.py` 保留高级/项目适配；`model.py` 固定任务快照、进度和取消；`preview.py` 生成本地对比页面。原生 `BatchRunner.cpp::run` 在阶段执行前按 source-pages 筛选源图；selectedPages 仍负责精确模式的逻辑选页。persistence.py 管理可移植偏好、任务身份和文件哈希校验；PDF 包装层共享渲染缓存，BatchRunner 共享前序分析检查点。实际处理仍由共享六阶段执行。

测试入口：`tests/workbench_integration.py`、`tests/menu_integration.py`、`tests/cli_full_integration.py`。`tests/render_workbench.py` 从实际布局模型输出 PNG，供宽窄窗口视觉检查。


## 中间图片设置（CLI 3.2）

从「处理方案 → 自定义常用设置 → 中间图片格式与压缩」进入。
PNG 默认等级 6，可输入 0–9；TIFF 可选无压缩/LZW/Deflate；JPEG 可输入质量 1–100。
只展示当前格式的选项，JPEG 显示有损与透明分层限制。子页「应用」保存到常用设置草稿，
再选择外层「应用设置」才影响任务；任一级取消均不改变已有任务设置。
「全部设置」也能编辑 `image_encoding`；不属于当前格式的压缩字段会被校验拒绝。
保存或载入设置文件会包含编码参数；任务执行使用固定设置快照，修改后旧预览不再代表当前设置；再次执行先确认并复用有效缓存。
编码规则与回退例外见 [CLI.md](CLI.md#cli-32中间页面图片的格式与压缩)。
## 完成后的页面切换（CLI 3.2.1）

任务进程退出、预览对比页生成和任务记录保存完成后，执行页自动进入结果菜单，无需再次点击「查看结果」。
成功、需复核、失败和已取消均显示各自结果状态；「正在取消」仍等待实际进程结束。
耗时在任务完成时冻结并保存为 job.json 的 elapsed_seconds，结果菜单显示固定耗时；旧任务没有该字段时不猜测耗时。
具体实现：model.Controller._read 发布终态和 finished 时间，ui.UI.monitor 在每次输入轮询前检查终态并切换到 results。


## 自动保存、DPI 与重复任务

常用设置、全部设置和运行选项在「应用」后自动保存到 `%LOCALAPPDATA%/ScanTailorCLI/menu/settings.json`，下次启动加载。尚未应用的草稿、输入路径和一次性的覆盖选择不会保存为默认值。通用 DPI、并发、编码和处理选项保留；按页规则、裁切框、区域和手动展平曲线只留在原任务快照，避免误套到新文档。被移除几何依赖的手动模式一并恢复为自动或关闭。配置损坏时显示原因并使用默认设置；「恢复默认配置」可重置包括 DPI、并发在内的偏好。

右侧 PDF 显示「渲染 DPI」，图片显示「输入 DPI」，另列「输出 DPI」。修改输出 DPI 不会修改 PDF 光栅化 DPI；两者同时展示，避免把仍为 300 的输入误认为输出修改未生效。按页 DPI 显示「按页配置」。

新任务的最终 PDF 位于所选目录根部；其余内容在 `_scantailor/` 下。已完成且校验通过的重复任务可直接打开结果；中断/缺失结果可继续，设置有变化时展示差异并可选择旧任务快照。覆盖只替换本次目标，最终 PDF 验证后发布；不会清空整个输出目录。阶段分析和预览也先显示计划并确认，再按校验结果复用已有阶段；运行日志会列出实际复用情况。

「继续未完成任务（沿用当时设置）」沿用该次任务的输入、完整设置、输出位置和操作类型；它不使用当前表单的新设置，预览也仍是预览。完成任务对应入口为「校验并补齐结果（沿用当时设置）」。需要使用新设置时回到工作台发起新任务；需要整本 PDF 时选择「开始处理」。
