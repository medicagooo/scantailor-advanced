# CLI screenshots and layout illustrations

## Actual Windows screenshots

Each language directory (`en/`, `zh-Hans/`, `zh-Hant/`) contains `cli-workbench-screenshot.png`, embedded as the hero image in its matching README. These are actual foreground-window pixel captures of ScanTailor CLI 3.4.0 running in Windows Terminal, taken on 2026-09-14 (Asia/Singapore), 1115 × 628 pixels. The terminal chrome is retained. No UI text was reconstructed, retouched or generated by AI; the empty-input start screen contains no document data. Font rendering reflects the local terminal.

The screenshot application was the local portable build `bin/ScanTailor-CLI-3.4.0-win64/scantailor-cli.exe`, implementation commit `b202df6e08eac86d216e7bcceb77837f53c57d57`. The terminal is launched normally; no shell commands are typed through UI automation. The window screenshot provider did not expose Windows Terminal, so foreground screen pixels were captured read-only using Pillow ImageGrab and the observed window bounds. All three saved images were visually inspected.

To reproduce, open the actual CLI in the desired language, then capture its visible window using a screenshot utility:

```powershell
.\bin\ScanTailor-CLI-3.4.0-win64\scantailor-cli.exe menu --language en --state-dir .\build-native\screenshots-actual\en
```

Use `zh-Hans` or `zh-Hant` for the other languages. Use a separate scratch state directory to preserve existing preferences/tasks. Keep the CLI window unobscured and exclude surrounding desktop content from published images.

## Existing layout illustrations

`cli-workbench.png`, `cli-image-encoding.png` and `cli-language.png` remain production cell-layout exports, not desktop screenshots. The encoding and language illustrations remain labelled in the README. Their generation uses `scripts/render_readme_images.py`, the real Workbench/Console layouts, Windows fonts and isolated presentation fixtures.
